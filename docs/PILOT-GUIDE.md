# Pilot Guide — Lessons 1, 7, 13, 17

**When:** Weeks 5–7 (28 September–18 October 2026)  
**Who:** 8 friendly students, ages 14–16  
**Why:** Validate timings and challenges before recording all 20 lessons (Programme Design §19.4)

---

## Lessons to pilot

| Lesson | Module | Why first |
|--------|--------|-----------|
| **1** — Is That Actually AI? | Foundations | Opening hook; sets programme tone |
| **7** — The Confidence Trap | Critical thinking | Defines programme character |
| **13** — Seeing Ideas | Creation | First major creative output |
| **17** — Build Without Code I | Building | Highest student engagement lesson |

---

## Recruitment

- [ ] 8 students: mix of Yerevan + one regional if possible
- [ ] Approved legal-representative permission and privacy notice completed before session 1
- [ ] Devices: phone or laptop; headphones optional
- [ ] One room or Zoom — facilitator observes, does not teach

---

## Session protocol (per lesson)

1. Watch video draft or run lesson live with facilitator script (~60 min total including pauses)
2. Time each phase: Hook, Discover, Watch, Try, Challenge, Reflect
3. Note where students stall >3 minutes without progress
4. Capture quotes (with permission) for landing page
5. Screenshot one artefact per student (blur faces if needed)

---

## Data to collect

| Metric | Target | Action if missed |
|--------|--------|------------------|
| Try phase completable in 15 min | 6/8 finish | Shorten steps or split video |
| Challenge posted willingness | 4/8 would post | Adjust social framing |
| Lesson total time | 50–70 min | Trim video or practical |
| Student quote quality | 2+ usable | Use in hero / showcase |

---

## After pilot (Week 7)

- [ ] Update `landing/index.html` showcase with real screenshots
- [ ] Add an approved 15-second pilot clip to the public page only after learner/guardian media permission and comms review
- [ ] Revise lesson scripts before full recording (Week 8+)
