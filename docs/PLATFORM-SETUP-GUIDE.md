## Guardian consent flow

```
Enrol form → age < 16? → guardian email required
         → confirmation email to guardian
         → guardian clicks confirm
         → student account created + course access
```

The approved notice must name the purpose, data fields, processing operations, recipients, retention, withdrawal/correction process, specific community channels, integrity policy, and one parent action (review the Workbook twice). Preserve evidence of consent and withdrawal in line with counsel's instructions.
