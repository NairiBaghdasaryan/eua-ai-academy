## Production rules (non-negotiable)

1. PAUSE & DO cards are **full-screen and silent** (5-sec countdown, then nothing)
2. Every demo shows **"recorded [Month Year]"** on screen
3. Presenter **fails on purpose** every lesson — keep in edit
4. Never tell students to break ToS (false age, VPN, borrowed accounts)
5. Console-only tools (Claude, ElevenLabs, Veo, Cursor) on presenter machine only
6. Do **not** film challenges — brief on camera, run in Telegram + Demo Day

---

## Shoot order rationale

**Lessons 1, 7, 13, and 17 first** — opening, character-defining critical thinking, first major creative output, and the first build. Lock production quality on these four pilot-tested lessons before batch recording.

## Presenter checklist (six rules)

1. Never answer first — ask "what would you do to find out?"
2. Fail on purpose every lesson
3. Talk to one person (second person singular)
4. Name that they already use AI for homework
5. Respect the pause — no "how did you get on?" immediately after PAUSE card
6. Never encourage rule-breaking for tools
