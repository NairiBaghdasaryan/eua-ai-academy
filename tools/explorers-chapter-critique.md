# AI Explorers: iterative chapter review

Review date: 14 September 2026. Scope: the English and Armenian web course. This is an editorial review, not evidence of learner-tested effectiveness or institutional accreditation.

| Chapter | Remaining learning gap | First proposed remedy |
| --- | --- | --- |
| 1. Understanding AI | Learners can repeat model terminology but may not choose between supplied context, fresh evidence, and calculation. | Add more definitions and a general capability list. |
| 2. Talking to AI | A framework can become a long prompt recipe; improvement is not demonstrated against fixed evidence. | Add another mnemonic and a polished prompt example. |

| 7. Practical Matters | Token arithmetic is clear, but cheap attempts and cheap accepted results can still be confused. | Add more price examples and token-saving tips. |
| 8. Practical applications | A catalogue creates possibility without ensuring a beginner finishes one useful artifact. | Add more use cases and a large required final project. |

## Round 2: reject weak remedies and refine

1. Reject vocabulary padding. Add a concrete three-request routing exercise that separates an explanation, a changing opening time, and an exact calculation. Show what evidence a response needs.
2. Reject another mnemonic. Hold source and criteria fixed, show the defect in a draft, repair only what failed, then test a changed constraint. Preserve CLEAR as the existing framework.
3. Reject checklist-only teaching. Supply a small fictional evidence packet with source ownership, publication date, event date, and a copied outdated claim. Produce a defensible answer with unresolved details visible.
4. Reject performative negativity. Ask for objections tied to budget, audience, and feasibility; keep one good idea, revise one weak assumption, and create a feasible minute-by-minute plan. Explain sycophancy without pretending disagreement proves truth.
5. Reject popularity as evidence. Compare two fictional outputs on identical tasks, apply permission gates before scores, test an edge case, and record a narrow decision. These are teaching outputs, not real product results.
6. Reject diagram complexity without consequence. Walk through a receipt, an ambiguous timeout, a retry decision, and a reconciliation result. Give the learner the exact state needed to decide whether an action may be repeated.
7. Reject "shorter always wins." Compare baseline, compact-but-incomplete, and compact-with-conditions at hypothetical rates, then divide by accepted outcomes and account for review time.
8. Reject a new mandatory project chapter. Keep all 100 existing ideas and add a bounded, optional worked studio within chapter 8: one dataset, a three-slide argument, an honest chart, and an accessible reviewable result.

## Round 3: acceptance criteria for the expansion

- Each chapter receives one substantial worked studio inside an existing section, not a new chapter.
- Each studio includes a self-contained fictional source, original prompt, visible intermediate decisions, a worked result, a comparison table, and an independent changed-input challenge with explanation.
- Prompt wording is not itself graded. Evidence, constraints, and the final artifact determine acceptance.
- The Armenian version carries the same facts, conditions, arithmetic, and task outcomes. English technical labels may accompany Armenian where useful, without replacing the explanation.
- Visuals show a relationship or a result. No decorative animation is required to understand a concept; all motion has a static/manual alternative.
- Existing practice pages, course navigation, access behavior, two-question self-check policy, and explicit chapter congratulations remain intact.
